## Data Analysis of Citibike: NYC's Official Bike Sharing System 
I conducted an analysis of Citibike: NYC's Official Bike Sharing System using R from February to June 2019. The analysis provides clear visualizations of the most popular usage hours, differences between subscribed and non-subscribed users, average trip distance and duration, and the most common starting locations.

## Dataset

The dataset used for this project is available on: https://drive.google.com/drive/folders/1NESuaJ5yGIrAli1TgrpnK5hnoxGsMi3h?usp=sharing

## Project Structure

- `bike_sharing.ipynb`: Notebook with the code used for analysis and plots
- `JC-2019xx-cibike-tripdata.csv`: datasets used for the project
